# 🎮 Pacman Game Collection

Welcome to the **Pacman Game Collection**! This repository hosts multiple implementations of the classic arcade game "Pacman", demonstrating how game logic can be ported across different programming languages.

## 🌟 Project Overview

This project serves as a fun and educational resource for developers interested in game development, logic porting, and seeing how the same mechanic is implemented in **Python** versus **Java**.

Whether you are a retro gaming fan or a coding enthusiast, there's something here for you!

## 🚀 Available Versions

### 1. 🐍 Python Version
A classic implementation using the `pygame` library. It features a complete game loop, ghost AI, and smooth controls.
- **Location**: `python_version/`
- **Tech Stack**: Python 3, Pygame

### 2. ☕ Java Version
A robust port using standard **Java Swing** for the GUI. No external game libraries required—just pure Java logic and painting.
- **Location**: `Java version/`
- **Tech Stack**: Java (JDK 8+), Swing, AWT
